Header получает контурные иконки из макета в docs: лупу, сетку, облачко и профиль;
для существующего Favoriten добавлено сердце. Тот же набор применяется в drawer
и нижней навигации, активный раздел подчёркивается. Названия ссылок и зоны нажатия
сохранены; на 1024–1199 px используются доступные подписи с подсказками,
от 1200 px — иконки рядом с текстом.

Проверки: lint, build, git diff --check, 44 UI-теста и снимки размеров 320–1440 px,
включая 1199/1200 px. Детали и текст координации с Яной:
[header-navigation.md](header-navigation.md).
