# Компактные фильтры каталога — 03.11.2026

В sidebar категории и города первоначально показывают первые четыре варианта.
«Alle Kategorien» и «Alle Städte» — отдельные действия сброса, не считаются
одним из четырёх. Кнопка «Alle anzeigen» раскрывает список; «Weniger anzeigen»
сворачивает его. По уточнению Ольги кнопка категорий видна при любом непустом
списке, включая нынешние четыре категории. При добавлении пятой и следующих
они автоматически окажутся за раскрытием. Для городов кнопка появляется,
уже при четырёх совпадениях; если городов больше, остальные скрыты до раскрытия.

Под «Alle Städte» добавлен shared Input «Stadt suchen». Ввод фильтрует весь
список доступных городов без учёта регистра и пробелов по краям, в том числе
города за пределами первых четырёх. После выбора radio город передаётся в
существующий API-фильтр, пагинация сбрасывается на первую страницу.
Сам поиск вариантов не сбрасывает ранее выбранный город и не отправляет
частичную строку как точное название города в API.

Диаметр radio — 14 px, без сжатия flex; кликабельная строка минимум 44 px.
Пустой результат поиска, загрузка и ошибка городов различаются; ошибка допускает
повторную загрузку. Shared Button/Input не дублируются, палитра и обе темы
используют текущие токены. Мобильные select-поля сохранены; меняется desktop-sidebar.

Проверка: пять catalog UI-тестов, включая шесть категорий/городов, раскрытие,
клавиатуру, поиск ранее скрытого города, размеры radio и фактический city/page в
API-запросе. Build/lint и diff check проходят. Тестовые API-ответы изолированы
в Playwright; новых категорий и городов в БД не создавалось.

## Уточнение оформления — 03.11.2026

Кнопки раскрытия используют локальные theme-токены primary-soft/emphasis/border
с повышенной специфичностью к shared Button. В тёмной теме больше нет белой
подложки с бледно-зелёным текстом. Hover тоже остаётся в текущей теме.
Shared UI глобально не менялся.

Последнее уточнение: кнопка городов видна и при четырёх доступных городах.
Все семь catalog UI-тестов прошли, включая цвета и раскрытие в обеих темах.
