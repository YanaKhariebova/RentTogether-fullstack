# Личная очистка истории Booking — 03.11.2026

Задача Ольги: небольшая корзина в Anfragen для завершённых и отменённых заявок.

## Поведение

- Кнопка доступна в Meine Mieten и Eingehende Anfragen только для COMPLETED/CANCELLED.
  PENDING, APPROVED, ACTIVE и REJECTED нельзя убрать этой операцией.
- Значок 18 px в кликабельной области 44 px; приглушённый красный цвет из темы.
- Диалог явно подтверждает удаление только из личного списка. После успеха
  карточка исчезает; при ошибке остаётся. Сохранение в БД переживает reload
  и смену устройства; localStorage не используется.
- Второй участник самостоятельно управляет своим списком.
- Booking, суммы, Conversation/Message и Notification физически сохраняются.
  Уведомления по скрытой заявке исключаются из списка и unreadCount только
  у скрывшего пользователя. Чат и его счётчик не меняются.

## Контракт и БД

DELETE /api/bookings/:id/history → 204 No Content.

Пользователя сервер берёт из сессии; клиент передаёт только ID заявки.
Неавторизованный запрос → 401, неверный UUID → 400, неизвестная/чужая заявка → 404,
недопустимый статус → 409. Повторный запрос безопасен, timestamp не перезаписывает.

Миграция: 20261103170000_booking_personal_history.
Две nullable колонки Booking: renterArchivedAt и ownerArchivedAt.
Существующие заявки остаются видимыми обоим участникам до явной очистки.

Новых env и зависимостей нет. После merge/deployment сначала применить миграцию,
затем обновить Prisma Client и backend, после — frontend:

```bash
npm --prefix server run db:deploy
npm --prefix server run db:generate
```

На локальной PostgreSQL миграция уже применена. Neon/Render не изменялись.

## Передача Яне

Этот пакет добавляет личную очистку Booking, а не удаление сообщений.
При объединении с новой моделью ITEM_INQUIRY сохранить обе новые колонки Booking
и отдельную миграцию. В Notifications service добавлены фильтры видимости по
текущему пользователю для списка и unreadCount; текущий DTO и read API сохранены.
Нельзя заменить эту операцию booking.delete: каскад уничтожит историю другого
участника и чат.
