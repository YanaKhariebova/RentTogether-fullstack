Frontend/backend build, lint, format:check и git diff --check проверены.
При первом запуске новых регрессионных тестов воспроизведены сбои пагинации и
исчезновения городов; после исправления тесты проходят.

Сквозной тест с двумя временными Development Clerk-аккаунтами проходит через
настоящие API и PostgreSQL: создание → два фото → reload → публикация → каталог →
публичная карточка → редактирование цены/обложки → повреждённый файл → сообщение
ошибки → исправление и повтор → удаление фото → запрет чужого PATCH/DELETE →
снятие с публикации → исчезновение из каталога → logout. Данные временных аккаунтов
очищаются; объявления Ольги не удаляются.

Повтор:

```sh
npm run test:items
npm --prefix server test
npm --prefix server run db:check
PLAYWRIGHT_CHANNEL=chrome npm run test:ui
PLAYWRIGHT_CHANNEL=chrome npm run test:auth
npm run build
npm --prefix server run build
npm run lint
npm --prefix server run lint
npm run format:check
```

Auth-тестам нужны настроенные Development Clerk, запущенная локальная PostgreSQL
и применённые миграции. Frontend/API тест запускает при необходимости; уже
работающие сервисы использует повторно. Прохождение CI не заменяет этот тест:
обычный CI пока не запускает браузер с настоящими Clerk-секретами.

## Локальный запуск

Три отдельных процесса: PostgreSQL, API и frontend. Все сейчас настроены на
localhost:55432, localhost:3000 и localhost:5174 соответственно. CLIENT_URL в
локальном server/.env должен совпадать с адресом frontend. После изменения dev
скрипта нужен один перезапуск backend; далее watcher следит также за .env.

При новом запуске, если сервисы ещё не работают:

```sh
# Терминал 1 — оставить открытым
npm --prefix server run db:local
# Терминал 2 — оставить открытым
npm --prefix server run dev
# Терминал 3 — оставить открытым
npm run dev -- --port 5174 --strictPort
```
