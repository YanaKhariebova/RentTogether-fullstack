# feat: improve mobile navigation, layouts and app installation

На телефоне верхняя панель и пять нижних разделов занимали слишком много места,
а текст Hero перекрывал людей. Теперь доступное боковое меню содержит все разделы,
вход/профиль/выход и тему, внизу остаются три основных действия. Мобильный Hero
использует облегчённый кадр исходной фотографии над текстом; desktop Hero сохранён.

Исправлены размеры календаря и touch-кнопок, tablet-фильтры, вкладки заявок,
safe area, отступы под фиксированную навигацию, поведение при фокусе полей и ошибки
избранного. Добавлены manifest, обычные/maskable PNG и Apple Touch Icon из текущего
логотипа. Service worker, offline booking, новые зависимости и изменения backend
не добавлены.

Проверки: lint, build, git diff --check; 64 UI-теста Edge, включая все семь ширин
320–1440 px, обе темы, клавиатуру, touch-emulation и фокус/закрытие меню.
Отдельная проверка настоящей Clerk-сессии покрывает профиль, избранное и оба списка
заявок в этой же матрице. Детали, установка и device/deployment checklist:
[docs/mobile-pwa.md](mobile-pwa.md).

Нужен командный review; установка через HTTPS и проверки на физических Android/iOS
остаются перед выпуском. В main автоматически не объединять.
